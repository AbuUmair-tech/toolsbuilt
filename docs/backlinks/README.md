# ToolsBuilt backlink kit

Ready-to-paste text for free listings, and emails for sites that may link to ToolsBuilt.
Every site below was opened and checked on 18 November 2026. Rules and prices change, so
look at each page again before you submit.

**Ground rules.** Never buy links, swap links ("I link you, you link me") or post the same
text on dozens of sites. Google treats those as link spam, and a new site can lose its
rankings for them. Everything here is free and editorial. Fazier and TinyLaunch are left out
on purpose: their free tiers require a link back to them, which is a link exchange.

## 2. Free listings: do these yourself (in this order)

### 2.1 GitHub "awesome" lists (best first step)

A pull request (PR) is a suggested edit on GitHub. Open the list, press the pencil icon on the
file, add one line, then "Propose changes" → "Create pull request". One list per PR, and read
each list's contributing file first.

**a) awesome-useful-websites** (1.3k stars) – https://github.com/atakanaltok/awesome-useful-websites
Add under **Calculators** (in the Academia section), in the same style as the lines around it:
```markdown
- [ToolsBuilt](https://toolsbuilt.com) - 50 free calculators (loan EMI, percentage, grade, GPA, age, dates) that run in the browser, in 9 languages, no sign-up.
```
PR title: `Add ToolsBuilt to Calculators`

**b) awesome-calculators** (277 stars) – https://github.com/xxczaki/awesome-calculators
Add under **Web** (format from its contributing file: `[Name](link) - Description.`):
```markdown
- [ToolsBuilt](https://toolsbuilt.com) - Free browser calculators for loans, percentages, grades and dates in 9 languages, with formulas and worked examples.
```
PR title: `Add ToolsBuilt`

**c) free-for-life** (1.8k stars) – https://github.com/wdhdev/free-for-life
Edit the right file in the `/data` folder (not README.md); the "For Students" category fits.
Keep it alphabetical, and no trailing slash on the URL:
```markdown
| [ToolsBuilt](https://toolsbuilt.com) | 50 free calculators for grades, GPA, CGPA, percentages, loans and dates. No sign-up, runs in the browser. |
```

**d) awesome-no-signup-tools** – https://github.com/Zio-Tibia/awesome-no-signup-tools
This list takes **one specific tool**, not a whole site, and asks you to test the privacy claim
yourself. Open the password generator, open the browser's developer tools → Network tab, generate
a password, and check that no request is sent. Then add:
```markdown
- [ToolsBuilt Password Generator](https://toolsbuilt.com/tools/password-generator/) - Strong passwords and passphrases generated in the browser with crypto.getRandomValues; nothing is sent to a server.
```

  when it really helps. Subreddits that ban self-promotion: answer without a link.

- Check Search Console → Links to see which sites now link to you.
