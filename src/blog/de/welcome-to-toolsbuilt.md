Es gibt keine Anmeldung und keine Werbung, und jede Berechnung läuft in deinem eigenen Browser. Auf dieser Seite erfährst du, was es auf der Website gibt, wie sie mit deinen Daten umgeht und wer sie baut.

Als ich mit ToolsBuilt angefangen habe, hatte ich eine Regel: Ein nützliches Tool sollte kostenlos, schnell und privat sein. Zu viele Online-Rechner verstecken das eigentliche Tool unter Werbung, verlangen ein Konto, bevor sie ein Ergebnis zeigen, oder schicken deine Eingaben an einen Server, über den du nichts weißt. ToolsBuilt soll in allen drei Punkten das Gegenteil sein.

## Was ist ToolsBuilt?

ToolsBuilt ist eine Website mit Tools für jeweils einen Zweck: Rechner, Umrechner, Generatoren und Formatierer. Jedes Tool erledigt eine Aufgabe auf einer eigenen Seite. Du gibst deine Werte ein und bekommst sofort das Ergebnis. Es gibt nichts zu installieren, kein Konto anzulegen und keine Begrenzung, wie oft du ein Tool nutzt.

Auf jeder Seite steht das Tool an erster Stelle. Darunter erklären die Rechner, wie sie zu ihrem Ergebnis kommen: die Formel, Rechenbeispiele mit echten Zahlen und häufige Fehler, gefolgt von Antworten auf häufige Fragen. Das Ziel ist, dass du ein Ergebnis selbst nachprüfen kannst, statt einer Zahl zu vertrauen, deren Herleitung du nicht siehst.

## Wie schützen die Tools deine Eingaben?

Die Berechnungen laufen per JavaScript in deinem Browser. Wenn du einen Kreditbetrag eingibst oder einen Text einfügst, berechnet das Tool das Ergebnis auf deinem eigenen Gerät, deine Eingaben werden also nicht an einen Server von ToolsBuilt gesendet. Sobald die Seite geladen ist, braucht die Berechnung eines Ergebnisses überhaupt keine Netzwerkanfrage mehr.

Der [Passwort-Generator](/tools/password-generator/) ist ein gutes Beispiel. Seine Zufallswerte stammen aus der eingebauten Browserfunktion [`crypto.getRandomValues()`](https://developer.mozilla.org/en-US/docs/Web/API/Crypto/getRandomValues), einer kryptografisch sicheren Quelle. Das Passwort wird auf deinem Gerät erzeugt und auf der Seite angezeigt. Es wird nirgendwohin gesendet und ist weg, sobald du den Tab schließt.

Drei Dinge solltest du wissen, damit du das vollständige Bild hast:

1. **Manche Tools merken sich deine letzten Eingaben.** Sie speichern sie im lokalen Speicher deines Browsers, damit sie beim nächsten Mal noch da sind. Diese Daten bleiben auf deinem Gerät, und die Schaltfläche „Zurücksetzen“ des Tools löscht sie.
2. **Ergebnis-Links enthalten deine Eingaben in der Adresszeile.** Nach der Berechnung kann die Seitenadresse deine Werte enthalten (zum Beispiel `?amount=1500000`), damit du das Ergebnis teilen oder als Lesezeichen speichern kannst. Teile so einen Link nur mit Menschen, die diese Zahlen sehen dürfen.
3. **Analyse-Tools laufen nur, wenn du zustimmst.** Google Analytics wird erst geladen, wenn du es im Cookie-Banner akzeptierst, und überhaupt nicht, wenn dein Browser Do Not Track sendet. Es zählt Seitenaufrufe, nicht das, was du in ein Tool eingibst. Die Einzelheiten stehen in der [Datenschutzerklärung](/privacy-policy/).

## In welchen Sprachen gibt es ToolsBuilt?

Jedes Tool und jede Seite gibt es in neun Sprachen: Englisch, Deutsch, Französisch, Spanisch, Portugiesisch, Indonesisch, Arabisch, Hindi und Urdu. Wechseln kannst du über das Sprachmenü oben auf jeder Seite. Die übersetzten Seiten verwenden dieselben Formeln und Beispiele, und arabische und Urdu-Seiten werden von rechts nach links gelesen.

Auch beim Anzeigen von Zahlen und Datumsangaben richten sich die Rechner nach deiner Sprache: Eine deutsche Seite schreibt Dezimalzahlen mit Komma, eine englische mit Punkt. Die Beträge selbst sind in jeder Sprache dieselben.

## Wie genau sind die Rechner?

Jeder Rechner verwendet eine anerkannte, veröffentlichte Formel, zeigt sie auf der Seite und rechnet echte Beispiele durch, damit du das Ergebnis von Hand nachprüfen kannst. Der Rechencode wird durch automatische Tests abgedeckt, die bestanden sein müssen, bevor eine Änderung live geht. Die Ergebnisse bleiben trotzdem Schätzungen und keine Finanz- oder Rechtsberatung.

Der letzte Punkt ist vor allem bei Geld wichtig. Ein Kreditrechner kann dir sagen, was ein bestimmter Zinssatz kostet, aber was du wirklich zahlst, entscheiden der tatsächliche Zins deiner Bank, ihre Gebühren und ihre Rundung. Wo ein Tool von Regeln abhängt, die sich ändern, etwa von Steuerstufen, nennt die Seite ihre Quelle und das Jahr, für das sie gilt. Wenn dir ein Ergebnis falsch vorkommt, melde es bitte zusammen mit den Zahlen, die du eingegeben hast.

## Wer baut ToolsBuilt?

ToolsBuilt wird von einer einzigen Person gebaut und gepflegt: [Abu Umair](/about/#author), der die Tools entwickelt und sich um die Ratgeber und Erklärungen auf jeder Seite kümmert. Die Website ist eine statische Seite, erstellt mit [Eleventy](https://www.11ty.dev/) und reinem JavaScript, ohne schwere Frameworks, und wird auf GitHub Pages gehostet. Der vollständige Quellcode ist [öffentlich auf GitHub](https://github.com/AbuUmair-tech/toolsbuilt).

Dass der Code öffentlich ist, gehört zum Datenschutzversprechen. Du musst mir nicht einfach glauben, dass ein Tool in deinem Browser läuft: Jeder, der JavaScript lesen kann, kann den Code des Tools öffnen und genau sehen, wie es sein Ergebnis berechnet.

Weil die Website schlank bleibt, laden die Seiten auch auf dem Handy schnell. Es muss kein Framework heruntergeladen werden, und die ausführlichen Erklärungen unter jedem Tool sind einfaches HTML.

## Wie kannst du ein Tool vorschlagen oder einen Fehler melden?

Schick eine Nachricht über die Seite [Kontakt](/contact/) oder nutze die Schaltfläche „Tool vorschlagen“ in der Fußzeile jeder Seite. Ideen für Tools, falsche Ergebnisse, missverständliche Formulierungen und Korrekturen an Übersetzungen sind alle willkommen. Gib bei einem Rechenproblem die Werte an, die du eingegeben hast, damit es nachvollzogen und behoben werden kann.
